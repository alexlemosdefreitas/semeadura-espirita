# Semeadura Espírita v0.8.4

## Distribuição

Aplicativo Android distribuído gratuitamente pelo projeto.

## Descrição pública sugerida

> Aplicativo gratuito para leitura, estudo e reflexão espírita, reunindo obras, leituras diárias, orações e conteúdos de estudo em um único ambiente.
>
> A versão distribuída pelo projeto foi concebida para permitir acesso offline aos conteúdos disponibilizados no aplicativo.

## Arquivo

`semeadura-espirita-v0.8.4.apk`

## Observação

Antes de publicar uma nova versão, atualize a versão no `config.js` e crie uma nova Release no GitHub.
